## 📋 Overview

**NHANES Data Analysis** is a data science project focused on analyzing public health data from the National Health and Nutrition Examination Survey. This project demonstrates advanced data analysis, statistical testing, and visualization techniques on real-world health datasets.

### Project Goals

🔬 **Exploratory Data Analysis** - Understand health patterns in population  
📈 **Statistical Analysis** - Identify correlations and relationships  
🎯 **Performance Metrics** - Evaluate analytical models  
💊 **Health Insights** - Extract actionable health findings

## 🚀 **Getting Started**

### Prerequisites

```bash
Python 3.7+
Jupyter Notebook
pandas, numpy, scipy
matplotlib, seaborn
```

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/piyush-hash/Nhane-Git-piyush.git
   cd Nhane-Git-piyush
   ```

2. **Create virtual environment**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install jupyter pandas numpy scipy matplotlib seaborn
   ```

4. **Launch notebook**
   ```bash
   jupyter notebook nhanes_data.ipynb
   ```

5. **Download NHANES Data** (if needed)
   - Visit [CDC NHANES Website](https://www.cdc.gov/nchs/nhanes/)
   - Download relevant datasets
   - Place in `data/` directory

## 📊 **Dataset Overview**

### NHANES Database

| Aspect | Details |
|--------|---------|
| **Source** | CDC - Centers for Disease Control & Prevention |
| **Participants** | 5,000+ individuals annually |
| **Variables** | 1,000+ health, nutrition, and demographic indicators |
| **Years Covered** | 1999-2018+ (continuous survey) |

### Key Data Categories

- 💪 **Demographic Data** - Age, gender, ethnicity, socioeconomic status
- ❤️ **Health Measurements** - Blood pressure, weight, body composition
- 🧪 **Laboratory Results** - Blood tests, cholesterol, glucose levels
- 🍽️ **Nutrition Data** - Dietary intake, food frequency
- 💊 **Health Conditions** - Diabetes, hypertension, asthma prevalence
- 💉 **Medications** - Drug usage patterns
